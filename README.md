# Fábrica de canais

Produção automática de vídeos animados (Mr. Squarington e outros canais).

- `motor/`: motor de animação (HyperFrames + GSAP), personagens, voz, boca, trilha
- `base/`: fontes, efeitos sonoros e cenários
- `canais/`: roteiros e cenas por canal
- `ferramentas/produzir.sh`: roteiro + cenas -> vídeo
